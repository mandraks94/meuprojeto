# IG Tools Pro - Extensão para o Chrome / Edge

Extensão completa e independente contendo 100% das funcionalidades do arquivo `instagram.js`.

## Como Instalar no Navegador:

1. Abra o navegador (Google Chrome, Microsoft Edge, Brave ou Opera).
2. Acesse a página de extensões:
   - No Chrome: `chrome://extensions/`
   - No Edge: `edge://extensions/`
3. Ative o **Modo do desenvolvedor** (chave no canto superior direito).
4. Clique no botão **"Carregar sem compactação"** (ou *"Load unpacked"*).
5. Selecione a pasta `extensao_instagram`:
   `C:\Users\je-md\OneDrive\Documentos\GitHub\meuprojeto\extensao_instagram`
6. Pronto! A extensão estará ativa e carregará automaticamente ao entrar no [Instagram.com](https://www.instagram.com).
